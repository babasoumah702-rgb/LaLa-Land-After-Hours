# LaLa-Land: After Hours

> 你不知道谁会打动谁。

一款发生在 queer-friendly 酒吧中的开放式拉拉向多智能体关系叙事游戏。

作品介绍页：https://babasoumah702-rgb.github.io/LaLa-Land-After-Hours/

## 当前版本

Windows Alpha v0.1.0。本仓库用于发布 Windows 可运行版本与版本记录。

## 核心体验

玩家进入一家即将打烊的酒吧，与四名拥有不同记忆、立场、关系状态和行动边界的角色自由交流。玩家可以输入自然语言、使用社交动作并在 3D 空间中移动；角色不仅回应玩家，也会彼此观察、判断、转述和影响。

## AI 与多智能体机制

- 每名角色拥有局部信息、个体记忆和独立关系判断；
- 玩家行为会形成可追溯的关系涟漪；
- 非角色化的“天道”机制注入受控意外，让角色自主产生不同反应；
- 大模型负责语义理解与角色化表达，确定性规则维护世界事实、空间可见性和状态边界。

## Windows 运行方法

1. 从 Releases 下载 Windows ZIP；
2. 完整解压压缩包，不要只在压缩包内直接运行；
3. 运行“启动游戏.cmd”或“LastCall.exe”；
4. 建议使用 64 位 Windows 10/11 并佩戴耳机体验。

在线模型模式需要联网并由体验者自行填写模型密钥；没有密钥时可使用离线规则模式。

## 开发状态

当前版本仍处于 Alpha 阶段，团队正在持续完善人物关系、多智能体逻辑、任务系统、角色资产和场景表现，并计划后续迁移至 Unreal Engine 5。
